# CWE bundle

`full/cwec_v5.0.xml` is the full official CWE List Version 5.0 XML download from MITRE, released October 28, 2026. The XML declares Schema 8.0 (`http://cwe.mitre.org/cwe-8`). The application parses weakness entries through `backend/taxonomy.py` and exposes the catalog version with each report.

Source: <https://cwe.mitre.org/data/downloads.html> (CWE Comprehensive View, XML ZIP).
